Hello everyone. This is our ChronosMatch project, a Python-based market simulation and matching system.

I will show the available project components and run the relevant tests to demonstrate that the implemented modules work as expected.

40–50 seconds — Dashboard

The dashboard displays mock market prices, including the best bid, best ask, and spread.

We have organised the project into separate modules and added tests and setup documentation. Thank you for watching our mid-review demonstration.
